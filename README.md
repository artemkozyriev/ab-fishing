## Структура
```
scripts/   — Node-скрипты (выгрузка данных, сборка данных приложения, дев-сервер)
data/      — сырые выгруженные данные (регуляции, геометрия водоёмов)
app/       — PWA (MVP): офлайн-справочник регуляций по водоёмам
```

## MVP (PWA) — как запустить
```bash
node scripts/fetch-regulations.mjs --geometry   # 1. выгрузить данные (уже сделано → data/)
node scripts/build-app-data.mjs                 # 2. собрать данные для app/ (app/data/)
node scripts/serve.mjs                          # 3. запустить → http://localhost:5173
```
Что умеет MVP: офлайн-поиск водоёма по названию, правила по видам (сезоны, лимиты, размеры, наживка),
«📍 Рядом» — по GPS определяет, на каком озере вы находитесь (point-in-polygon), и показывает
ближайшие. Работает офлайн (service worker). Подробнее — [app/README.md](./app/README.md).

## TL;DR стратегии
1. **Дифференциатор:** офлайн-справочник регуляций Альберты **по каждому водоёму** + карты глубин. НЕ «ещё один прогноз клёва» (это уже у Fishbrain/ANGLR).
2. **Ключевая техническая находка:** структурированные регуляции доступны через API
   `https://geospatial.alberta.ca/services/Fisheries/Regulation?waterbodyId=<WB_ID>` (JSON, без авторизации) + геометрия водоёмов через ArcGIS REST (лицензия OGL–Alberta). ⚠️ По регуляционному API нужно получить письменное разрешение провинции перед запуском.
3. **Рынок:** ~250 000–285 000 рыболовных лицензий/год в Альберте.
4. **Стек:** старт как офлайн-PWA (быстро, $0) → нативная обёртка React Native + Expo/EAS (офлайн-SQLite, сборка iOS без Mac, OTA-обновления регуляций без ревью).
5. **Бюджет входа в сторы:** $25 Google (разово) + $99/год Apple ≈ $124.
