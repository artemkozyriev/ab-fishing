## Позиционирование
**Офлайн-first справочник рыбалки для Альберты**: регуляции по каждому водоёму + карты глубин + (позже) прогноз клёва и агрегация местных отчётов. НЕ конкурируем с Fishbrain/ANGLR на «прогнозе клёва по погоде» — берём гиперлокализацией и офлайном.

## Что делаем / чего НЕ делаем
| ✅ Делаем | ❌ Не делаем (пока) |
|---|---|
| Офлайн-регуляции по водоёмам (ядро) | Глобальный охват (только Альберта) |
| Карты глубин (169 озёр, AGS) | Facebook-скрейпинг как фундамент |
| GPS «где я → что можно» | Соцсеть рыбаков «как Fishbrain» |
| Reddit-агрегация (фаза 2) | Продажа лицензий (Private Issuer — нерелевантно) |
| Прогноз клёва (фаза 2, поверх локальных данных) | Прогноз клёва как стартовая фича |

## Стек (предварительно)
- **MVP:** PWA (service worker + IndexedDB + GPS) — $0, мгновенный запуск.
- **v1:** React Native + Expo + EAS — единый код iOS/Android/Web, сборка iOS без Mac, нативный SQLite (офлайн), OTA-обновления регуляций (EAS Update).
- Данные регуляций → локальный SQLite, обновление по сезонам через OTA.

## Монетизация (предварительно)
- Freemium: бесплатно — базовые регуляции; платно — карты глубин, расширенный прогноз, доп. водоёмы.
- Основной SKU — **годовая подписка с триалом**; **lifetime** как второе предложение (~5x годовой).
- Affiliate: **FishingBooker** (20–50%, гиды) — приоритет; Bass Pro/Cabela's CA (~5.6%).
- Цель раннего этапа: $10–50/мес, затем рост.
- Долго: бренд + мерч.
